# The three parts of an official run (117 problems, 2026-10-31)

Each part has the same mix of difficulties: the problems of every difficulty class in
`proofbench/ProofBench/DATABASE/Database.json` were dealt in turn (sorted by id) to the three
parts, so a problem's part is fixed by the database, not by any model's results. Running a
model in parts lets the data be checked between parts; the parts of one model and setting
are one run of the benchmark and are reported together.
